# FrameForge — Anime & TV Poster Studio

A Vite + React + TypeScript poster editor.

Upload a background image, look up anime metadata using Jikan, look up TV show metadata using TVMaze, edit the poster copy, preview it live, and export a 3840 × 2160 PNG.

## Requirements

- Node.js 22
- npm

## Run locally

Install dependencies:

```bash
npm install
